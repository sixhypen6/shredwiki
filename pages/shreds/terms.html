Shredder Terms & Terminology

A standardized reference index clearing up shredder community slang, historical naming shifts, structural framework distinctions, and combat exploit mechanics.

1. Mechanical Distinctions & Terminology Shifts

1.1 Demean vs. Cutter Enhancement (CE)

Much of the confusion around these terms comes from a historical shift in community slang:

  • Historical Context: "Demean" was originally the legacy term used for specific rotational speeds (47.124, 31.416, etc.). As engine theory evolved, the community adopted Cutter Enhancement (CE) to describe speed tuning, while Demean shifted to specifically mean blade clipping and recoil dampening.
  • Cutter Enhancement (CE): Refers strictly to rotational frequency alignment. CE tunes blade rotational speed (MotorSpeed) relative to point count ($p$) using $\text{Speed} = (60 / p) \times \pi$ to sync cutter block sweeps directly with the server's 60Hz physics tick rate.
  • 2-Motor CE ("2-Motor Demean"): Because stacking two motors (e.g., two motors at 23.562 reaching the 47.124 threshold) naturally dampens constraint shock like a Damp Blade, players often mislabel this as "2-motor Demean." Technically, it is a 2-motor CE setup.
  • Demean Mechanics: Refers strictly to recoil suppression and constraint dampening that enables blade clipping. It operates independently of motor speed or blade rotation—phase-clipping can occur even at 0 speed.
  • Damp Blade: An add-on configuration designed specifically to absorb structural shock on impact, preventing severe recoil feedback from flinging the shredder core.

1.2 Full Massless (Desync) vs. True Anti-Gravity

A build hovering motionlessly in mid-air is often mislabeled as "Anti-Grav," but the underlying physics engine cause determines what is actually happening:

  • True Anti-Gravity (Hover Thruster Dampening): Built using Hover Thrusters set to Max Drag and 0 Speed (or low speed) pointing outward in any direction. Max drag applies severe position-locking drag vectors that neutralize gravity and lock the build in 3D space.
  • Full Massless "Hovering" (Desync Fake): Occurs when every block in an assembly is set to massless. Because the engine cannot perform proper center-of-mass calculations, the craft experiences severe client-server desync. On other players' screens, the build appears frozen or floating, but it is actually a server physics glitch, not real anti-gravity stability.

2. Structural Frameworks: Skeleton vs. Exoskeleton

Understanding structural attachment methods is crucial for building survivable shredder frames that resist cutter block destruction.

2.1 Skeleton (Base Chassis)

The Skeleton is the internal base spine or central chassis. It serves as the primary mounting hub where core components—such as motors, gyros, and drive modules—are directly attached.

2.2 Exoskeleton (Invincible Weld Harness)

An Exoskeleton is an external structural harness utilizing invincible weld setups to maintain connection across disconnected or damaged blocks.

  • Without an Exoskeleton (Linear Chain): If Block A is attached to the anchor, Block B is attached to A, and Block C is attached to B—destroying Block A causes B and C to detach and fall. Destroying Block B leaves Block C stranded.
  • With an Exoskeleton (Invincible Framework): Blocks A, B, and C are independently welded to an invincible outer harness element. If Block A or B is completely destroyed by incoming cutter damage, Block C remains welded to the harness, floating, connected, and fully operational.
