This article is about axis locks. For gyro cores, see Gyro Cores.

Axis locks are the main functionality of shredders. They are used for movement control by limiting the rotation of a part, which lets you use it as a base for aiming.

There are two categories of axis lock: preventative and correctional. Some are stronger than others.

Correctional Axis Locks

This type of axis lock actively keeps the part at the same rotation; if it is twisted against the axis lock, it will be corrected.

Method Strength Complexity
Gyro Low Low
Balljoint Low-Medium High
Void Lock High Low-High

Gyro

Gyro axis lock simply requires the use of a gyro block, which uses the BodyGyro function to apply a correctional axis lock to the block.

It is proportional to mass, which makes it the weakest (but still decent) form of axis lock, and it cannot function when massless. There is a fix for this: Staging Gyros.

Balljoint

Balljoint Axis lock is a corrective form of axis lock that works by void/NaN deleting one end of an already activated mouse-guided balljoint. It doesn't work via TNT, gun, or cutter deletion. The balljoint becomes an axis lock because mouse tracking is disabled; it is slightly stronger than a standard gyro.

Void

Void axis lock is created by stretching out any non-teleporting constraint past its pull reach (generally 100k studs). This causes an effect where only rotation-correcting forces apply, without any position-correcting forces.

It is the strongest form of axis lock if paired with a hinge constraint (motor), providing both a preventative and corrective form of axis lock on every axis besides the one the motor spins on. Using 3 motors pointing at all 3 axes yields the best stability.

Preventative Axis Locks

This type of axis lock increases the difficulty of rotating the assembly it affects.

Method Strength Complexity
ANO Medium Medium
Torque Lock Very High High

Torque

Torque lock is a powerful form of axis lock using the moment of inertia principle to create a resistant preventative lock. It is created by offsetting 3 or more parts of equal mass an equal distance from the center. Paired with a gyro block, it becomes extremely resistant to twisting.

ANO

Forced axis lock, known as ANO, utilizes rotation-correcting forces from prismatic constraints by twisting and offsetting a part connected via a prismatic constraint. Because it is a preventative lock rather than corrective, it is usually paired with a gyro block (known as Hybrid Lock / Anoscope).
