1. Massless Mechanics & Engine Rules

A massless module successfully strips physical weight from an assembly when three specific engine conditions are met:

  • Motor2 Torque: The drive Motor2 must be configured to 100 Torque or higher.
  • Root Part Hierarchy: The target assembly being made massless cannot be the designated Root Part of the build or the first child of the root assembly. Anchoring the massless module bypasses this root restriction during activation.
  • Rotational Velocity Threshold: The object must maintain a minimum rotational velocity magnitude of 1.0 or higher.
Scripted Immunity Exclusions:

Certain components possess hardcoded engine immunity to massless state propagation. This includes Motor1 plates, Motor2 plates, and internal wing panel joints controlling aerodynamic drag.

1.1 Massless Assembly Desync

Massless application can trigger severe desynchronization across assembly groups that lack a designated root part between themselves and the activating Motor2.

Engine Cause: When activated, the engine creates an unmanaged internal variable storing all assembly blocks to evaluate for part immunity. Because this variable is never cleared by the engine thread, the server treats the massless module and the host build as a unified group, while the client evaluates them as separate parts. This root part mismatch leads to network desync.

Mitigation: Bypassing this desync requires forcing root part priority. Stacking centralized mass within the core assembly guarantees that the main build always retains primary root part status over the massless module.

2. Staging Mechanics

2.1 Staging Constraints

Massless state propagation does not cross constraint boundaries (separate assemblies connected via joints, except when linked by balljoints). To extend massless properties across the whole build, separate assemblies must be temporarily welded using staging blocks.

  • Springs: The most common staging method. Springs disconnect cleanly upon unanchoring without leaving residual welds, provided neither end is welded to the primary frame.
  • Disconnectors: Functional for staging, but leave behind non-collidable residual geometry on the host assembly.
  • TNT Staging: TNT set to 0 Pressure / 0 Radius deletes cleanly upon activation without leaving geometry behind.
TNT & Compressor Bug:

Avoid using TNT staging on builds utilizing compressor blocks or tight rotational angles. Collision overlap bugs between compressed geometry frequently prevent TNT from detonating correctly.

2.2 Staging Blade Motors

Shredder blade assemblies require staging across their motor joints, or the massless state will fail to pass into the blade structure. Locking the primary Motor1 (or locking all drive motors in multi-motor stacks) temporarily bridges the constraint boundary during spawn.

Motor Plate Mass Warning:

Motor1 plates retain their physical mass even after successful staging. Avoid placing blade motors far from the center of mass to prevent violent rotational wobble.

2.3 Preventing Massless Gyro Degradation

Gyroscopes lose torque and holding force when made massless because Roblox gyro stability scales proportionally with assembly mass.

Fix Procedure:

  1. Place a lockable Motor1 underneath the gyro assembly.
  2. Connect both ends of the massless module's Motor2 together using staging blocks.
  3. Upon spawning: unlock the Motor1, break the staging connection on the Motor2, and re-lock the Motor1. Binding both the motor lock and staging blocks to the same keybind allows rapid execution via a quick double-press.

3. Massless Module Evolution

3.1 Balljoint Massless (Modern Meta)

The current meta standard. Bypasses root part constraints by routing rotational torque through a balljoint assembly, enabling massless propagation even across anchored or multi-stage builds.

3.2 Three-Block Massless (Deprecated)

A streamlined historical iteration utilizing a 3-block anchor and Motor2 setup. Effective on simple unanchored builds, but fails to propagate across complex multi-assembly or anchored structures.

3.3 Ancient Massless Module (Super Deprecated)

The original legacy massless configuration. Utilized redundant structural blocks prior to the discovery of core engine root part manipulation.
