Void Tech

Void Tech is a physics manipulation mechanic centered around Axis Lock (preventative and corrective) and Void Surge. It is achieved by flinging a non-teleporting constraint past its pulling point while an anchor module remains anchored.

  • 2 Core Characteristics
  • 3 Recommended Constraints

1. Architecture Topology

Standard Void Tech relies on a stacked 3-tier modular connection topology separated by vast stud distances:

  • BUILD: The primary vessel or payload structure being stabilized. Connected to the Battery via a 100k+ stud separation gap.
  • "BATTERY": Intermediate power/state distribution unit positioned between the primary build and the charger.
  • "CHARGER": Base anchor module linked to the Battery via N studs. Responsible for storing and releasing constraint tension.
Terminology Note: The Charger holds high-torque constraint velocity/tension in a locked state before release. The Battery maintains and feeds the resulting displaced state to the primary Build.

2. Core Characteristics

  • Basic & Strong Surge: Generates significant positional displacement/jitter whenever the module anchor is activated. Void surge is notably stronger than standard Antivoid surge.
  • Void Immunity: Grants immunity against falling beneath the world void threshold and boundary resets.
  • Axis Lock: Provides directional and rotational stability depending on constraint selection.
  • No Native Void Fling: Standard Void Tech configurations do not natively support void flinging without RD/Antivoid modifications.

3. Recommended Constraints

While various physics joints exist, Void Tech is **best paired with HingeConstraints** (used by both standard Hinges and Motor blocks).

Physics Insight: Under the hood, Hinges and Motors run on identical HingeConstraint logic. Their high torque capacity and predictable rotational limits make them ideal for maintaining stable Axis Locks without snapping prematurely.
